# Chaser Agent evaluation case-study and redaction contract

The Chaser Agent calibration workflow can become a public case study only after the operator approves the exact export. Local evaluation evidence is not automatically marketing material.

## Public-safe story

The useful story is the process:

- a versioned agent harness receives a repeatable source-review case;
- the runner produces an immutable evidence bundle and execution trace;
- automated checks expose structural weaknesses;
- a human reviewer labels claim relevance, missing context and action linkage;
- the harness is changed and re-run;
- baseline and candidate results are compared through regression gates.

## Redact before screenshots, video or social posts

- absolute local paths, usernames, device names and repository locations;
- private source text, credentials, tokens, account identifiers and channel IDs;
- reviewer names unless the reviewer explicitly approves attribution;
- personal correction notes not written for publication;
- internal commit references, unpublished roadmaps and approval-control details;
- any imported file whose privacy class is not explicitly public;
- browser tabs, notifications or surrounding desktop content outside the Studio;
- claims about improved quality unless the baseline, candidate and scoring evidence are visible and reproducible.

## Preserve in the public evidence

- the Studio product identity and independent workspace model;
- the harness and dataset version labels when public-safe;
- the original public-source URL;
- the distinction between automated evaluators and human judgment;
- the immutable run/review lineage;
- explicit blocked boundaries: no spend, external action, memory promotion or training;
- the final evaluation result only when the operator has actually completed it.

## Marketing proof gate

“Used with Chaser Agent” requires a visible run and review flow. “Improved Chaser Agent” additionally requires a later candidate run and evidence-backed comparison. “Industry-standard” should be described as the design target until independent users, interoperability checks and external evaluation evidence support the stronger claim.

Publication, deployment, screenshots, video capture and social posting remain separate operator-approved actions.
